# Lecture 6 – Animation


## Goals

After this lecture you can:
- use CSS transitions for simple hover and focus effects
- use **Motion** for mount animations, gestures, exit animations (`AnimatePresence`) and layout animations
- respect users who prefer reduced motion

## 1. Packages
- Motion (formerly Framer Motion): `npm install motion`


## 2. Study the code
In the app **`react-lectures`**, study:

- `10.Animation/`
  - `MotionBasics.tsx`: `initial`/`animate`/`transition`, `whileHover`/`whileTap`, springs, `whileInView`
  - `AnimatePresenceExample.tsx`: exit animations
  - `StaggerList.tsx` and `LayoutAnimation.tsx`: variants, stagger and layout animations (in more depth for VG)
